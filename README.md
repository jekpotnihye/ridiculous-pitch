A program that writes one sentence, at most 200 characters, pitching a bizarre startup idea that sounds ridiculous at first glance yet holds together as a real business. The sentence names the odd thing being sold, who pays for it, and why the business makes sense. The program writes the sentence as a single text file to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
